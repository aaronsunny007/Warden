\begin{abstract}
Warden inspects the three channels an attacker can reach in the Model Context Protocol (tool
descriptions, arguments and outputs), tracks session taint, and enforces a signed, hash-bound
policy. A red/blue loop proposes defences from confirmed bypasses, and an eight-stage validation gate
checks that each is harmless to benign work before it may enforce. We report measured results with
confidence intervals, including negative results. \textbf{Results here use a simulated victim agent;}
see Section~\ref{sec:limits}.
\end{abstract}
